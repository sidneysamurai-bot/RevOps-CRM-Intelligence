## Why this exists

Anyone can format a spreadsheet. The point of this series is the reasoning chain a Revenue Operations role actually gets paid for:

```
CRM data → metrics → analysis → insight → business decision
```

Every workbook here uses live formulas (never hardcoded results), and every analytical assumption — forecast category rules, risk-flag thresholds, known data gaps — is documented in the relevant week's `Forecast_Reference` tab or `Insights.md`, not buried in a cell.
